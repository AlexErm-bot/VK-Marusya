# VK Marusya
Онлайн-платформа **«VK Маруся»** для поиска и просмотра информации о фильмах: случайный фильм дня, топ-10 по IMDb, каталог по жанрам, избранное и авторизация пользователя.

## 📋 Функциональность

- **Главная страница** — случайный фильм с обложкой и описанием (кнопка «другой фильм»)
  и топ-10 фильмов по рейтингу IMDb.
- **Жанры** — список жанров в виде карточек.
- **Страница жанра** — фильмы, отфильтрованные по жанру, с бесконечной подгрузкой
  по 10 штук.
- **Страница фильма** — обложка, полная информация, кнопка трейлера (модальное окно
  с видео) и кнопка добавления/удаления из избранного.
- **Поиск** — модальное окно с поиском фильмов по названию.
- **Авторизация и регистрация** — модальное окно с валидацией полей; сессия на cookie,
  сохраняется при перезагрузке страницы.
- **Аккаунт** — данные пользователя и список избранных фильмов; выход из аккаунта.

## 🛠 Стек

- **React 18** + **TypeScript**
- **Vite** — сборка и дев-сервер
- **React Router v6** — маршрутизация
- **Redux Toolkit** — управление состоянием
- **Axios** — работа с API (`withCredentials: true` для cookie-сессий)
- **SCSS** / CSS Modules — стилизация
- **react-hook-form** + **zod** — валидация форм

## 🚀 Запуск проекта

### Требования
- Node.js ≥ 18
- npm ≥ 9 (или yarn/pnpm)

### Установка и запуск

1. Клонировать репозиторий

```bash
git clone https://github.com/AlexErm-bot/vk-marusia.git
```

2. Перейти в папку проекта

```bash
cd vk-marusia
```

3. Установить зависимости

```bash
npm install
```

4. Запустить дев-сервер
   
```bash
npm run dev
```
Приложение откроется по адресу http://localhost:5173 (порт по умолчанию у Vite).

## ⚙️ Сборка production:

```bash
npm run build
npm run preview
```

## 📁 Структура проекта

- `src/api/` — axios-инстанс, эндпоинты, типы ответов
- `src/components/` — переиспользуемые компоненты (MovieCard, GenreCard, Modal и другие)
- `src/pages/` — страницы приложения (HomePage, GenresPage, GenrePage, MoviePage, AccountPage)
- `src/store/` — Redux Toolkit: slices и store
- `src/hooks/` — кастомные хуки (useAuth, useFavorites и другие)
- `src/styles/` — глобальные стили, SCSS-переменные, миксины
- `src/utils/` — хелперы и константы
- `src/types/` — общие TypeScript-типы
- `src/App.tsx`, - `src/main.tsx` — точка входа и корневой компонент

## 🔌 API

- Документация: `https://cinemaguide.skillbox.cc/docs/`
- Авторизация работает на cookie-сессиях: в axios включён `withCredentials: true`;
- Cессия восстанавливается при старте приложения запросом профиля;
- При истечении сессии пользователь разлогинивается автоматически.
